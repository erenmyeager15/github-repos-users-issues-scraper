# GitHub Scraper Promotion Notes

## Positioning

Promote this as an official-API GitHub metadata scraper for public repositories, users, organizations, and optional nested issues.

Best-fit buyers:

- Open-source program offices.
- Developer-tool teams researching ecosystems.
- Technical due-diligence analysts.
- Engineering and data teams tracking repository activity.

Avoid positioning it as a spam, scraping-private-repos, or personal-contact enrichment tool.

## Short Video Ideas

1. "Export GitHub repository metadata to CSV with Apify"
2. "Scrape public GitHub repos with the official API"
3. "Track open-source projects by stars, language, topics, and issues"

## Suggested Demo Flow

1. Open the Actor.
2. Use `openai/openai-node`.
3. Keep issues disabled and `maxResults: 1`.
4. Run the Actor.
5. Show repository fields and export options.
6. Mention that a GitHub token is best for larger runs.

## SEO Keywords

- GitHub scraper
- GitHub repository scraper
- GitHub API data export
- scrape GitHub repos
- open source intelligence
- GitHub to CSV

## Short Social Copy

Built a GitHub Scraper for Apify using the official GitHub API.

Input:
- repo names
- usernames/orgs
- search queries

Output:
- stars, forks, topics, language, license
- public repo metadata
- optional issues and user repos

Useful for open-source research, project monitoring, and technical market analysis.
